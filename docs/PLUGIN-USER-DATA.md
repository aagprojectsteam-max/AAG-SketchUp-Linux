# Plugin user data

The Windows source contains Fredo default parameters, parameter-manager data and
vaults, plus Chaos cloud/configuration directories. Their filenames and sizes
are recorded in a private local inventory. Their contents were not imported.

Extension code, portable presets, UI preferences, caches and licensing are
separate categories. First verify clean extension code with fresh defaults.
Then review any requested preset individually for absolute Windows paths,
external textures, account fields, version compatibility and personal data.
Use a new destination name and preserve its source. Never bulk-copy AppData or
browser profiles.

No user preset was required for the tested pipe and face tools. Test models were
generated locally, including Hebrew filenames. They are not public repository
artifacts. An unclassified PDF in a source extension folder is excluded from the
code migration. No Windows SKP or user asset was edited.
