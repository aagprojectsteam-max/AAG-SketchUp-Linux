# Baseline

The 2026-09-28 baseline recorded Ubuntu 26.04.1, kernel 7.0.0-34-generic, GNOME 50.1 on Wayland/Xwayland, Intel Arc MTL and hardware Mesa/OpenGL support. Steam Flatpak was installed with a user mask/background restriction. YAWMS was disabled and retained a stale Steam window. Multiple Wine/Proton experiments existed; unrelated Wine applications remained active.

The application had not been launched before this baseline was collected. Later findings supersede the old crash hypotheses. The technical sequence is preserved in [HISTORY.md](HISTORY.md); full original inventory stays in private local evidence.
